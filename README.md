## ⭐ Featured Project

### 🔬 [BioScout — Agentic Biomedical Research Assistant](https://github.com/bensonkachappilly/biomedical-research-assistant)

**[🌐 Live demo](https://biomedical-research-assistant.streamlit.app)** · An AI agent that answers biomedical questions using live evidence from PubMed, citing every claim so it can be verified.

Built end-to-end as a production-minded system: an agentic tool-calling loop, a custom **MCP server** (usable inside Claude Code), **RAG** over PubMed, guardrails against hallucinated citations, observability traces, an automated **evaluation suite**, **CI/CD** on GitHub Actions, and a **Docker**-containerised, publicly deployed UI.

`Claude (Anthropic SDK)` `MCP` `RAG` `Agents` `Evals` `CI/CD` `Docker` `Streamlit` `Python`

## 📊 Data Science Projects

### 🎯 Reinforcement Learning

- **[Golf Club Selection: UCB vs Q-Learning](https://github.com/bensonkachappilly/golf-ucb-qlearning)**
  Modelled golf club selection as a multi-armed bandit / MDP problem. Compared a pure UCB baseline against a Q-function approach with discounted future reward estimates. Includes a Tkinter animated visualisation of the learned policy.
  `Python` `NumPy` `Tkinter` `RL`
- **[Maze Solver: Off-Policy TD Control](https://github.com/bensonkachappilly/maze-off-policy-td-control)**
  Applied off-policy temporal difference control (Q-Learning) to solve a maze navigation problem. Evaluates convergence across different exploration strategies.
  `Python` `NumPy` `Reinforcement Learning`
